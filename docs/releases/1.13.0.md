# KeiHome 1.13.0

本页记录 KeiHome 1.13.0 系列的更新，正文与 App 内三语更新日志一致。

## 简体中文

适配新版 HyperOS 系统桌面，改善大图标包的导入与应用、最近任务图标显示，以及手机和平板上的 Glass 交互。

1. **适配系统桌面 0308 和 9261**

   更新应用名称、Dock 与搜索栏材质、Monet 的动态解析。支持时可选择系统默认、双行或滚动名称。修改材质设置后，桌面已显示的图标也会刷新高光效果。

2. **最近任务图标随主题更新**

   切换深浅色或图标主题后，已在后台的任务也会更新卡片图标。改善电话、安全服务、主题壁纸等使用不同入口组件的任务识别。

3. **启动图标跟随系统动画缩放**

   开启「启动图标补全」后，符合条件的纯色系统启动页会优先显示已应用的主题图标，缺少时使用应用原图，应用自带的启动图案和品牌标识会保留。图标随窗口一起展开，保留原有比例和留白。启动途中上滑回桌面，或在窗口收起时再次点开，图标都会跟着窗口缩放。

4. **大图标包导入与应用更稳定**

   分批处理和校验大型 Monet 归档，降低内存峰值。实体机验收覆盖 APK、ZIP、MTZ、内置和生成图标包，包括一个有 49,252 个映射的图标包。改用系统文件选择器，并改善受支持的 MTZ 分层资源保留。

5. **生成与应用进度更清楚**

   居中弹窗同时展示当前阶段、整体百分比，以及可统计阶段的已处理数和总数。百分比会随阶段内的处理进度推进。支持的 HyperOS 设备可在主题壁纸小窗中完成应用。

6. **Monet 图标补全可独立调整留白**

   为图标包中未适配且符合条件的应用生成 Monet 图标。单独的留白开关可缩进铺满画布或贴边的图案。推荐映射、自定义图标和保留原始图标共用匹配与渲染链路。

7. **桌面外观小工具**

   在「桌面 → 小工具」查看壁纸与状态栏外观信息。状态栏颜色难以辨认时，可以手动刷新状态栏外观。

8. **沉浸式手势导航栏**

   在「桌面 → 沉浸式手势导航栏」可单独开启柔光玻璃手势条。背景从条身透出，两端的高光随系统手势动画变化，开关立即生效。关闭柔光玻璃后，开启「跟随底栏取色」可让普通手势条更快适应所选应用的深浅页面。切换中途返回时，手势条也更容易看清。更改取色设置后请完全退出并重新打开对应应用。

9. **哔哩哔哩首页底栏延伸至屏幕底边**

   在 LSPosed 勾选哔哩哔哩作用域并开启专属适配后，哔哩哔哩会自动加入适用应用。支持的首页可将主题原图或纯色底栏延伸到手势区，状态卡显示已安装版本和最近的适配结果。

10. **手机与平板的 Glass 界面改进**

   更新到 MIUIX 670cf597 snapshot，并采用更多上游 Glass 组件。宽屏下打开详情页时仍可使用分组侧栏导航，弹窗、底部面板、搜索和列表滚动也更加一致。使用向导补齐图标包操作说明，可直达桌面小工具与沉浸式手势导航栏。

11. **更新后自动重试热重载**

   覆盖安装新版后，即使没有打开 KeiHome，仍在运行且尚未加载新版的受支持进程也会在后台自动重试。部分 LSPosed 版本的通知只显示首次重载结果。连续更新时，系统界面会释放旧版柔光玻璃手势条占用的资源。

> 本版包含原生库更新。升级后请手动重启设备，并解锁进入桌面以加载新版本。退出升级日志后会显示重启提醒。桌面与手势导航栏的实际支持取决于系统和应用版本。更改图标生成选项后请重新应用图标包。

## English

Support for the new HyperOS Home release, more reliable large icon packs, consistent icons in Recents, and a refreshed Glass interface for phones and tablets.

1. **HyperOS Home 0308 and 9261 compatibility**

   Updated dynamic detection for app labels, Dock and Search materials, and Monet. App names can use system, two-line, or scrolling display where supported. Mounted icon highlights refresh when the material setting changes.

2. **Recents icons follow the current theme**

   Task cards refresh their icons after appearance or icon theme changes, including tasks already running in the background. Improved matching for Phone, Security, and Themes when their launch entries use alternate components.

3. **Launch icons scale with the window**

   Turn on Fill missing launch icons to show the applied theme icon on supported plain system splash screens. If the theme has no matching icon, the original app icon is used. Apps keep their own splash artwork and branding. The icon keeps its proportions and padding as the window expands. If you swipe Home during launch or tap the icon again while the window is closing, the icon scales with the window in either direction.

4. **More reliable large icon packs**

   Process and verify large Monet archives in batches to reduce peak memory use. Physical-device checks covered importing and applying APK, ZIP, MTZ, built-in, and generated packs, including one with 49,252 mappings. Improved the system document picker handoff and preservation of supported layered MTZ artwork.

5. **Clearer generation and application progress**

   A centered dialog shows the current stage, overall percentage, and processed and total counts when available. Percentages advance with the work reported within each stage. On supported HyperOS devices, Themes opens in a small window for applying the pack.

6. **More control over Monet fallback icons**

   Generate Monet artwork for eligible icons missing from the pack. An independent switch makes room around artwork that fills the canvas or reaches its edges. Recommended mappings, custom icons, and original-icon choices share the matching and rendering path.

7. **Desktop appearance tools**

   Open Desktop tools to check wallpaper and status-bar appearance information and refresh the desktop appearance configuration if contrast becomes difficult to read.

8. **Immersive gesture bar**

   Open Desktop → Immersive gesture bar to turn on the soft glass handle. The background shows through, and highlights at the rounded ends follow the system gesture animation. The switch takes effect immediately. With soft glass off, turn on Match bottom bar color to help the plain handle adapt more quickly when a selected app switches between light and dark pages. The handle is easier to see if you go back mid-transition. Fully close and reopen those apps after changing the color settings.

9. **Bilibili home artwork reaches the bottom edge**

   Grant the Bilibili scope in LSPosed and enable the dedicated setting to add Bilibili to the selected apps automatically. Supported home layouts extend theme artwork or a solid tab bar color into the gesture area. The status card shows the installed version and the latest result.

10. **Glass refinements for phones and tablets**

   Updated to the MIUIX 670cf597 snapshot and adopted more upstream Glass controls. Wide windows keep grouped sidebar navigation on detail pages. Refined dialogs, sheets, search controls, and list scrolling across window sizes. The first-use guide explains the icon pack workflow and links directly to Desktop tools and the immersive gesture bar.

11. **Automatic hot reload retries after an update**

   After you install an update, KeiHome retries hot reload in the background for supported processes that are still running an older version, even if you never open KeiHome. Some LSPosed versions show only the first attempt in the notification. SystemUI also releases resources used by earlier versions of the soft glass handle across updates.

> After upgrading, manually restart the device and unlock to the home screen to load the new native libraries. A restart reminder appears after you leave the upgrade notes. Launcher and gesture navigation support depend on the installed system and app builds. Reapply the icon pack after changing generation options.

## 日本語

新しい HyperOS ホームに対応し、大容量アイコンパックの適用、最近使ったアプリのアイコン、スマートフォンとタブレットの Glass UI を改善しました。

1. **HyperOS ホーム 0308 と 9261 に対応**

   アプリ名、Dock と検索バーのマテリアル、Monet の動的検出を更新しました。対応環境ではアプリ名をシステム標準、2 行、スクロールから選べます。マテリアル設定を変更すると、すでにホームに表示されているアイコンのハイライトも更新されます。

2. **最近使ったアプリのアイコンがテーマに追従**

   ライト・ダークやアイコンテーマを切り替えると、バックグラウンドに残っているタスクのアイコンも更新されます。電話、セキュリティ、テーマなど、起動時と実行時でコンポーネントが異なるタスクの照合を改善しました。

3. **起動アイコンがウィンドウに合わせて拡大・縮小**

   「起動アイコンを補完」をオンにすると、対応する単色のシステム起動画面に適用中のテーマのアイコンが表示されます。テーマに該当するアイコンがない場合は、アプリ本来のアイコンを使います。アプリ独自の起動画像やロゴはそのままです。アイコンは元の比率と余白を保ってウィンドウと一緒に広がります。起動中に上へスワイプしてホームに戻ったり、閉じる途中でもう一度タップしたりすると、アイコンもウィンドウの動きに追従します。

4. **大容量アイコンパックのインポートと適用を改善**

   大容量の Monet アーカイブを分割して処理・検証し、ピーク時のメモリ使用量を抑えます。49,252 件のマッピングを含むパックをはじめ、APK、ZIP、MTZ、内蔵パック、生成済みパックのインポートと適用を実機で確認しました。システムのファイル選択と、対応する MTZ レイヤーの保持も改善しました。

5. **生成と適用の進捗を表示**

   画面中央のダイアログに、現在の段階、全体の進捗率、集計できる場合は処理済み件数と総件数を表示します。進捗率には各段階内の処理状況も反映されます。対応する HyperOS 端末では、テーマを小ウィンドウで開いて適用できます。

6. **Monet 補完アイコンの余白を調整**

   パックに対応するアイコンがない場合に、条件を満たすアプリの Monet アイコンを生成できます。独立した余白スイッチで、キャンバス全体を覆う絵柄や端に接する絵柄を縮小できます。推奨マッピング、カスタムアイコン、元のアイコンの保持で共通の照合・描画処理を使います。

7. **ホームの外観ツール**

   ホームのツール画面から壁紙とステータスバーの外観情報を確認できます。ステータスバーが見づらい場合は、ホームの外観設定を手動で更新できます。

8. **没入型ジェスチャーバー**

   「ホーム → 没入型ジェスチャーバー」でソフトガラスのジェスチャーバーを個別に有効にできます。バー越しに背景が透け、両端のハイライトがシステムのジェスチャーアニメーションに合わせて変化します。切り替えはすぐに反映されます。ソフトガラスをオフにして「下部バーの色に合わせる」をオンにすると、対象アプリで明るい画面と暗い画面を切り替えた際に、通常のジェスチャーバーの色がより早くなじみます。切り替えの途中で戻ってもバーを見失いにくくなります。色の設定を変更した後は、対象アプリを完全に終了して開き直してください。

9. **ビリビリのホーム画面を下端まで表示**

   LSPosed で Bilibili のスコープを許可して専用設定をオンにすると、対象アプリに自動で追加されます。対応するホーム画面では、テーマ画像や単色の下部バーの背景がジェスチャー領域まで続きます。状態カードにはインストール済みのバージョンと直近の適用結果が表示されます。

10. **スマートフォンとタブレットの Glass UI を改善**

   MIUIX 670cf597 スナップショットに更新し、上流の Glass コンポーネントをさらに採用しました。幅の広いウィンドウでは詳細画面でもグループ化されたサイドバーを使えます。ダイアログ、シート、検索、一覧のスクロールも調整しました。初回ガイドでアイコンパックの使い方が分かり、ホームのツールや没入型ジェスチャーバーを直接開けます。

11. **更新後のホットリロードを自動で再試行**

   上書き更新後は KeiHome を開かなくても、旧版のまま動作している対象プロセスでホットリロードを自動的に再試行します。LSPosed のバージョンによっては、通知には初回の結果だけが表示されます。更新を繰り返した際は、システム UI が旧版のソフトガラスバーのリソースを解放します。

> 更新後は端末を手動で再起動し、ロックを解除してホームを開いてください。新しいネイティブライブラリが読み込まれます。更新履歴を閉じると再起動の案内が表示されます。ホームとジェスチャーナビゲーションの対応状況は、システムやアプリのバージョンによって異なります。アイコンの生成設定を変えた場合は、パックを再適用してください。
