# KeiHome 1.8.0

发布日期：2026-11-12（按 `v1.8.0` 目标提交时间）

范围：`v1.7.0..v1.8.0`。

重做完美图标补全计划的资源同步与管理，新增自定义遮罩和对比预览，让下载、预览与实际应用的关系更清楚。

1. **按样式下载，后续增量更新**

   完美图标资源改为匿名 Git 同步：首次获取所选样式及其共享资源，后续复用本地内容，只下载需要变化的部分；可查看远端版本和更新时间，已下载样式可离线使用。

2. **重新设计资源管理**

   列表区分可用与已下载样式，支持过滤、单项更新和删除，以及进入选择模式后批量下载或移除；已下载条目可查看大小，并选择更新、删除、预览或关闭，危险操作需再次确认。

3. **更完整的同步反馈**

   同步期间临时显示阶段、进度及耗时，结束后自动收起；完善共享资源的大小统计、失败与中断提示，并在返回上级页面时刷新本地状态，保留上次可用资源。

4. **优先展示常用样式**

   新用户默认选择 HyperOS4，样式菜单优先排列 HyperOS4、HyperOSClassic、HyperOS3、Hyper 和默认；保留用户已保存的选择。

5. **自定义图标遮罩**

   新增图标遮罩子页。自动补全默认开启：优先使用图标包已有遮罩，缺少时补用 HyperOS4 遮罩；可导入自己的 transform_config.xml，或恢复自动选择，并保留特殊图标配置。

6. **统一图标预览与遮罩对比**

   APK、MTZ／ZIP、完美图标和 Apple 方案共用遮罩渲染规则，可对比原始、HyperOS4 与自定义遮罩的真实图标效果；当前已应用主题的预览仍读取实际应用配置，避免与待生成设置混淆。

7. **完善动态分层资源校验**

   检查动态条目的配置、静态预览层和动画资源，保留符合规则的原有格式；缺损资源不会被误当作完整动态图标，减少预览与生成异常。

8. **更熟悉的交互与及时刷新**

   统一 OS4 二次确认弹窗、图标操作和资源选择工具栏；优化页面返回、下载状态与预览联动，减少重复计算和不必要重组，同时保留进度及状态更新。

9. **内置更新日志与新版向导**

   设置新增分版本更新日志。首次安装进入使用向导，版本前缀变化后展示一次日志；本次升级默认展开 1.8.0、1.7.0、1.6.0，手动查看时只展开当前版本，并同步补充资源下载、遮罩及预览说明。

> 遮罩导入和预览不会自动应用主题。修改遮罩或生成选项后，请更新或重新生成图标并应用；特殊图标资源会保留自身规则，预览中的动态内容以静态快照呈现。
