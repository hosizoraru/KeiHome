Source baseline: `102145eb0d4b1b357c752776f96a669fb7585f82`.

change the application or module behavior.

## Space accounting

| Item | Size |

The raw deletion covered 26 explicit project targets and 302 project-specific
temporary roots. The net figure subtracts the retained archive/input footprint;
it is not the gross size of the deleted trees. Global free-space changes also
include unrelated host activity and are not used as the reclamation claim.

Research assets now live inside ignored `.artifacts/` instead of scattered
temporary directories. The repository directory therefore includes these local
assets; excluding `.artifacts/`, the checkout and current APK occupy about
16.3 MiB. See [the research index](README.md) before recreating an old `/tmp` path.

## Verification and recovery

Every evidence/diagnostic archive member was hashed after compression and
compared with its source before deletion. Protected APK, wrapper and
`local.properties` hashes were checked after deletion. The old temporary roots
contained no nested repositories; symlinks inside the discarded duplicate
environment were not followed. No active build or capture was using the targets.

The host test's relocated defaults are checked against the two retained ELF
hashes. Local documentation links and Git whitespace checks are validated.
No Gradle build or device test is run for cleanup, and no versionCode change or
installation occurs. The next build recreates intermediates.

Recover only the release mapping if needed:

