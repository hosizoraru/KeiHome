# KeiHome 1.6.0

发布日期：2026-11-11（按 `v1.6.0` 目标提交时间）

范围：`v1.5.0..v1.6.0`。

新增 Apple 图标方案与完美图标补全计划，扩展系统场景的图标跟随，并完善动态资源和桌面兼容性。

1. 新增 Apple 图标方案，可选择 iOS、iPadOS 或 macOS、深浅色、分辨率与圆角，支持本地缓存、手动及批量匹配、映射导入导出。

2. 新增完美图标补全计划入口，支持同步资源、选择风格、本地生成与预览，并可将已下载的资源用于未覆盖系统应用的图标回退。

3. 完善 MTZ / ZIP 的原生分层、深浅色与受支持动态资源的识别和导入；Apple 日历、时钟可使用原生动态资源，预览显示静态快照。

4. 为完美图标补全计划新增可选的深色适配，支持静态分层图标及符合规则的动态分层资源；优先保留原有独立深色资源，预览与生成选项保持联动。

5. 让受支持的最近任务、通知应用图标、HyperOS 系统分享、设置应用管理／详情及安全服务侧边栏跟随当前图标包、深浅色和 Monet 配色。安全服务适配缓存会识别 APK 内容变化，避免同版本号换包时误用旧结果。

6. 修复下载管理和部分预置非系统应用在 ColorOS 回退时图标过小的问题；依据原厂包与签名识别可用原生图标，并补全主题壁纸、主题商店到 ColorOS 主题商店的映射。

7. 完善支持的 APK、MTZ 图标包的 Monet 联动与深浅色预览，保留来源声明的名称、版本、作者和设计者信息，减少未知名称及来源识别异常。

8. 优化大图标包的压缩包读取、嵌套资源计量和原始条目复制，减少重复解压、图片复制及预览缓存占用；同步或生成失败时保留上次可用资源。

9. 完善 API 102 热重载时的旧代监听、缓存和后台任务回收，减少跨进程重载失败及深浅色刷新遗漏；最近任务中较早的应用图标也可在支持范围内更新。

10. 完善 9239 版系统桌面兼容性，覆盖 Dock、Monet 等功能，并保留不支持时的原生行为。

11. 识别 Pad 与桌面实际支持的能力，保留 Pad 原生 Dock；未适配的手机专用功能显示兼容状态，避免套用手机布局，并保留已保存选项。

12. 精简图标包页面的重复提示与操作文字，新增可选的顶栏帮助，突出应用、更新入口和已声明的作者信息；修复底栏切换跳动，改进大字体布局。

13. 完善首次启用、作用域授权和使用向导说明，区分已授权、已加载及实际生效状态；首次启用建议授权后重启系统一次，后续更新通常使用自动热重载。

图标效果取决于图标包资源和系统支持。已有图标方案需更新或重新生成后应用，才能取得相关资源修正；新增作用域需在框架中授权，并由对应进程加载模块。未适配的入口保留系统原生图标。
