# KeiHome 1.7.0

发布日期：2026-11-11（按 `v1.7.0` 目标提交时间）

范围：`v1.6.0..v1.7.0`。

全面更新为 MIUIX OS4 风格，重新整理桌面设置、状态信息与使用向导，并修正图标圆角和部分深色图标白边。

1. **OS4 界面与双风格底栏**

   迁移按钮、菜单、展开收纳与玻璃组件，统一操作图标和简短文字；底栏保留 iOS-like 与 OS4 Glass 两种风格可选。

2. **桌面功能分组**

   将 Dock、外观、图标与启动整理为独立子页，首页显示简短桌面版本和故障状态；功能顺序与状态 pill 对应，变更时在对应选项下显示等待进度。

3. **分开设置 Dock 与搜索栏质感**

   Dock 可在自己的子页设置质感，搜索栏可独立选择或跟随 Dock，减少跨页面寻找设置的困惑。

4. **更紧凑的状态与图标包设置**

   连接、同步、失败及中断信息改为清晰的状态 pill；将更多设置和图标预览选项归入图标包板块，优化 Monet 状态、跳转和顶部操作。

5. **直观的缓存空间管理**

   以圆柱图与分类展示空间占用，支持跳转管理相关资源；提供可编辑的清理提醒阈值，默认按是否下载完美图标资源使用 500 MB 或 1 GB，不会自动删除资源。

6. **重写作用域授权与使用向导**

   授权页分别显示各作用域、组件版本和授权状态；五步向导支持继续、稍后设置及重新查看，区分授权、加载与实际生效，并说明部分功能的联动设置。

7. **默认图标圆角与白边修正**

   默认补全缺失的原生图标配置，改善第三方图标包下回退图标变方、深色边缘发白的问题；优先保留图标包已有配置，可在更多设置中关闭补全。

8. **完善系统组件兼容性**

   补充 8607 版桌面和安全服务 13.8.1 的结构解析验证，继续按实际代码与资源识别兼容能力，避免单纯依赖版本号。

> 图标效果仍取决于资源和系统支持。已有图标方案需更新或重新生成并应用，才能使用图标配置修正；授权不等于对应进程已经加载或功能已经生效。
