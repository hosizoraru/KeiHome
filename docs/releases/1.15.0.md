# KeiHome 1.15.0

本页与 App 内三语更新日志一致，对比归档的 1.14.0 构建 `1.14.0+gb020e23.b0727.override`（`114000727`）。

## 简体中文

新增深浅色壁纸搭配，恢复深色模式下调暗壁纸，并改进图标包和 App 外观设置。

1. **为浅色和深色选择不同壁纸**

   在「桌面 → 桌面外观 → 深浅色壁纸搭配」为两种模式分别选择一套系统个性化搭配。切换系统深浅色时，HyperOS 会应用对应的桌面、壁纸和锁屏样式。也可以为任一模式选择保持当前搭配。

2. **分别调暗桌面与锁屏壁纸**

   打开「深色模式下调暗壁纸」后，可分别设定强度，对照原图和调暗效果，点按滑块轨道或拖动调整。桌面和锁屏共用动态壁纸时，锁屏和解锁也会按各自强度切换。

3. **App 外观和配色独立设置**

   在「设置 → 主题设置」单独选深浅色外观和 App 配色，同页调整显示效果。「关于」页换用 Glass 卡片，滚动时会在顶栏显示标题。

4. **保留更多原版图标分层**

   转换兼容的 Hyper 图标包时，会保留更多分层图案，以及受支持的时钟、日历和天气动效。完美图标补全计划可选「普通图标固定深色」，在深浅两种模式下为符合条件的普通图标使用深色图案。

5. **改善三款深色图标**

   KeiHome 额外补全中的密钥认证保留了钥匙孔和对勾，VPN 热点保留了信号弧线和钥匙的光影，文件眼的圆环在深色底上更清晰。

6. **减少启动天气时的图标开销**

   完美图标补全计划对需要查询外部天气服务的动态图标使用原版静态图，避免桌面同步等待。天气 App 和小组件会继续更新天气数据，时钟、日历等受支持的动效也会保留。

7. **通知图标跟随深浅色和图标包**

   切换系统深浅色或图标包后，状态栏和通知中心会刷新应用图标，已经显示的通知也会更新。

8. **修复启动图标和 Dock 柔光玻璃**

   使用默认图标主题并开启「启动图标补全」时，符合条件的系统启动页优先显示匹配的 HyperOS 应用图标，修复部分图标呈方形或与桌面不一致的问题。桌面进程重启后会恢复 Dock 柔光玻璃材质。

9. **减少桌面图标刷新的重复工作**

   单个应用发生变化时，桌面仅刷新该应用的图标和快捷方式。主题刷新也减少重复读取图标包的开销。

10. **Glass 面板和搜索操作**

   底部面板开合与回弹采用更新后的 Glass 动效。搜索框有统一的清除按钮，清空关键词后可以继续输入。

> 壁纸功能需要启用系统框架作用域，搭配可用性取决于 HyperOS。要应用图标改进，请更新或重新生成图标包后应用。

## English

Choose wallpaper presets for light and dark mode, dim wallpapers in dark mode, and find new options for icon packs and app appearance.

1. **Different wallpapers for light and dark mode**

   In Home → Appearance → Wallpaper presets by appearance, choose a System Personalization preset for each mode. HyperOS applies its Home and Lock screen appearance when the system switches modes. Either mode can keep the current preset.

2. **Separate dimming for the Home and Lock screens**

   Turn on Dim wallpaper in Dark mode to set each strength separately. Compare the original and dimmed previews, then tap the slider track or drag to adjust. A live wallpaper shared by both screens switches strength when you lock or unlock.

3. **Separate app appearance and palette settings**

   In Settings → Theme settings, choose a light or dark appearance and an app palette independently. Display effects are on the same page. About now uses Glass cards and reveals the title as you scroll.

4. **More original icon layers**

   Converting compatible Hyper packs preserves more layered artwork, including supported clock, calendar and weather effects. In Perfect Icons, the optional Fixed dark for ordinary icons setting uses the dark image in both modes for eligible ordinary icons.

5. **Clearer dark icons**

   In KeiHome extra icons, Key Attestation keeps its keyhole and checkmark, VPN Hotspot keeps its signal arcs and key shading, and Fileyan’s ring stands out against its dark background.

6. **Less work when opening Weather**

   Perfect Icons uses the original static icon for weather icons that query an external provider, avoiding synchronous waits in the launcher. Weather data in the app and its widget still updates, and other supported animations such as the clock and calendar are preserved.

7. **Notification icons follow appearance and icon pack changes**

   The status bar and notification center refresh app icons after a light or dark mode switch or an icon pack change, including notifications already on screen.

8. **Launch icons and Dock glass fixes**

   With launch icon completion enabled and the default icon theme selected, eligible splash screens use matching HyperOS app artwork where available, fixing some square or mismatched icons. Dock Soft Glass restores its material after the launcher restarts.

9. **Less repeated work during Home icon refreshes**

   When an app changes, the launcher refreshes its icons and shortcuts without scanning all apps. Theme refreshes also skip redundant icon archive reads.

10. **Glass sheets and search controls**

   Bottom sheets use updated Glass motion on open, close and settle. Search fields use a consistent clear button so you can start a new query right away.

> Wallpaper features require the System Framework scope. Presets depend on HyperOS support. Update or regenerate and apply your icon pack to use the icon improvements.

## 日本語

ライトモードとダークモードで壁紙セットを切り替え、ダークモードで壁紙を暗くできるようになりました。アイコンパックとアプリの外観設定も改善しました。

1. **外観モードごとに壁紙を選択**

   「ホーム → 外観 → 外観モード別の壁紙セット」で、システムのパーソナライズから各モードのセットを選べます。システムの外観が切り替わると、HyperOS が対応するホーム画面とロック画面の外観を適用します。現在のセットを維持することもできます。

2. **ホーム画面とロック画面の壁紙を個別に調整**

   「ダークモードで壁紙を暗くする」をオンにすると、画面ごとに強さを設定できます。元の画像と調整後を見比べながら、スライダーをタップまたはドラッグして調整できます。同じライブ壁紙を使う場合も、ロックとロック解除に合わせて強さが切り替わります。

3. **アプリの外観と配色を個別に設定**

   「設定 → テーマ設定」で外観とアプリの配色を個別に選べます。表示効果も同じページで調整できます。「このアプリについて」は Glass カードを使い、スクロールするとタイトルが表示されます。

4. **アイコンの元のレイヤーをさらに保持**

   対応する Hyper アイコンパックの変換時に、より多くのレイヤーを保持します。時計、カレンダー、天気の対応エフェクトも維持します。Perfect Icons で「通常アイコンをダークに固定」を選ぶと、対応する通常アイコンはライトモードでもダーク画像を使います。

5. **ダークアイコンを見やすく改善**

   KeiHome の追加アイコンで、キー認証には鍵穴とチェックマークを、VPN ホットスポットには電波の弧と鍵の陰影を残しました。Fileyan のリングは暗い背景でも見やすくなりました。

6. **天気アプリ起動時のアイコン処理を軽減**

   Perfect Icons では、外部の天気プロバイダーを参照するアイコンに元の静止画像を使い、ホーム画面での同期待ちを減らします。天気アプリやウィジェットの天気情報は引き続き更新され、時計やカレンダーなどの対応アニメーションも維持します。

7. **通知アイコンを外観とアイコンパックに合わせて更新**

   ライト／ダークモードやアイコンパックを切り替えると、ステータスバーと通知センターのアプリアイコンが更新されます。表示済みの通知にも反映されます。

8. **起動アイコンと Dock のソフトガラスを修正**

   標準のアイコンテーマで起動アイコンの補完を有効にすると、条件を満たす起動画面に対応する HyperOS のアプリアイコンを表示し、一部のアイコンが四角く見えたり、ホーム画面と異なって見えたりする問題を修正しました。ホーム画面の再起動後は Dock のソフトガラスが復元されます。

9. **ホーム画面のアイコン更新処理を軽減**

   アプリに変更があったときは、そのアプリのアイコンとショートカットだけを更新します。テーマの更新時にアイコンパックを繰り返し読み込む処理も削減しました。

10. **Glass パネルと検索の操作を改善**

   ボトムシートを開閉するときの Glass アニメーションを更新しました。検索欄のクリアボタンを統一し、キーワードを消してすぐに入力を続けられます。

> 壁紙機能にはシステムフレームワークのスコープが必要です。壁紙セットは HyperOS の対応状況に依存します。アイコンの改善を反映するには、アイコンパックを更新または再生成して適用してください。
