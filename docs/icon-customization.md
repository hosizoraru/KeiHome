# 图标自定义

入口位于「图标包 → 图标补全与回退 → 图标自定义」。

先选择应用，再选择本机可用的来源图标包和具体图标。来源包含已安装 APK、
已导入 ZIP/MTZ、内置与已生成的图标包。Apple 和完美图标补全计划先生成一次，
即可作为来源使用。图标支持应用名称和包名搜索，也可以清空搜索浏览全部资源。

保存后重新应用当前图标包；后续切换图标包时自动带上这些选择。自定义与
「保留原始图标」互斥，双向切换均提示确认。只有资源保存成功后才取消保留；
从保留页面切换时，只有移除自定义成功后才勾选保留。移除后也需要重新应用。
同包名在不同用户空间使用同一选择。

## 资源与优先级

自定义保存来源图标自身的原生静态、深浅色、MAML/分层资源，不带入来源包的全局
遮罩、主题配置或其他应用。存入 files/custom-icons，独立于可清理的图标包缓存。
保存使用新资源文件和同步提交的元数据，失败或取消时保留旧选择。

所有类型在 IconPackHandoffs.prepare 的共同出口覆盖。基础包、补全、原始图标与
遮罩完成后，清除目标应用所属的旧资源树，写入自定义资源和带包名的 Activity 别名。
不使用跨应用共享的全局类名。旧资源的 fallback provenance 同步剔除，避免误认来源。
旧配置意外同时存在保留与自定义时，出口仍以自定义为最终覆盖，界面通过确认流程互斥。

没有自定义时保持原有 v9 generation 格式；存在自定义时使用 v10，写入选择及资源摘要。
设置变化会触发「需要重新应用」判断；预览当前已应用主题时仍读取实际主题文件，
不会把未应用的设置冒充已经生效。

## 加载与边界

仅进入功能后读取设置和应用信息；包事件合并并增量读取，停止页面生命周期时注销观察。
大目录搜索在后台执行，结果与来源快照和查询绑定，避免显示过期搜索结果或串图。
预览并发有界，列表投影使用快照身份键，避免重复深比较映射。

自定义的应用选择和保留原始图标共用轻量应用清单，默认在加载名称、图标前排除资源覆盖、
测试包，以及没有桌面入口且没有专用图标的后台组件。不会仅凭 vendor 包名前缀屏蔽应用，
有图标的系统前端仍保留。筛选菜单可开启「显示系统组件与测试包」，已有保存项始终可见。
切换显示范围重新读取清单，普通安装、更新与移除继续只查询受影响的包名。

应用列表展示原始图标，选择来源与确认时保留原始图标作为对照。来源列表优先展示本地与
已安装图标包，并预览目标应用的对应图标；未覆盖时明确标为示例，展示设置、联系人、
相机等代表图标，仍可进入选择其他图标。预览匹配在后台执行，位图加载继续复用有界队列。
ColorOS 内置包使用本地化风格名称，只在资源清单明确启用时附加 ART+；关闭时只显示
风格名称，不从文件名猜测开关状态。已保存选择在来源仍可用时也使用当前语言与这一简洁格式。

最多 256 项选择，单项解压资源最多 32 MiB，全部最多 64 MiB。只在明确保存与应用时
读取完整资源，普通列表展示读取缩略图。缺少或损坏已保存资源时应用失败，保留当前主题，
不会悄悄退回别的图标。来源包后续更新不会改变已保存图标，需要主动重新选择才更新。
