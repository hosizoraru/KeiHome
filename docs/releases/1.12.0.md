# KeiHome 1.12.0

本页记录 1.11.0 → 1.12.0 的三语更新说明。签名产物、源码身份与本地验收结果归档在发布记录中；本地 release tag 与推送、公开发布分别处理。

以下三语正文对应 App 内 `release_notes_1_12_0_introduction`、`release_notes_1_12_0_changes`、`release_notes_1_12_0_footnote`。保留 [1.10.0](1.10.0.md) 与 [1.11.0](1.11.0.md) 历史原文，不将旧版原生适配或重启要求重复列为本版新增。

## 简体中文

完善逐应用图标自定义，重整 Monet 配色编辑，改善搜索与刷新，并让大图标包导入和存储管理更清楚。

1. **逐应用自定义图标优先**

   从本地图标包为应用指定图标，切换图标包后继续使用；自定义是最终覆盖，与保留原始图标切换时需确认。已保存项先打开原图与自定义图标对照，再编辑或移除；修改后重新应用。

2. **更清楚的范围、预览与搜索**

   应用和图标选择提供带数量的视图、范围筛选与搜索，打开预览或选择步骤时收起键盘并保留查询。计算新匹配时保留当前结果，减少输入中的加载闪烁。更新日志按版本保存全部／未读状态，与重启建议分别记录。

3. **Monet 配色集中编辑**

   概览提供快速下拉选择，取色来源、配色方案与图标预览使用独立面板；自定义色彩和配色详情进入子页查看。修改保留为草稿，通过同一个「应用配色」悬浮按钮提交，保持当前启用／关闭状态；开关单独控制。刷新只读取系统状态。 右上角帮助集中说明草稿、独立开关、灵感图标包和对比度。

4. **完善大包导入与本地应用**

   改善大型 ZIP／MTZ 和完美 iOS 完整包的读取、校验与系统主题交接，提供准备进度与取消，并在需要时检查导入工作空间。复用符合条件的生成归档，修复受支持动态日历及原生配色模板被误拒的问题；未知程序仍不放行。

5. **更顺畅的应用刷新与原生下拉**

   合并安装、更新与移除事件，只重读受影响应用，减少滚动时重复目录比较。相关页面采用原生下拉刷新，改善禁用状态与 overscroll 的衔接，以及 Glass 工具栏、页签阴影和间距。 MIUIX 图标统一采用 Glass 风格，操作菜单按用途组织，排序可直接勾选，筛选子菜单展示当前选择。

6. **按类别管理图标包存储**

   显示导入副本大小，从存储页分别进入 MTZ／ZIP、Apple 和完美图标管理。清理预览内存、下载资源和生成归档分别操作；仅保留最新生成包在下次生成成功后清理旧生成版本，手动导入副本独立保留。

7. **导出 App 日志前等待 20 秒**

   导出前展示用途说明，确认按钮需等待 20 秒。App 日志用于 KeiHome 自身界面、设置与崩溃问题；图标、桌面和模块功能异常仍请提供 LSPosed 日志。

> 图标资源或规则变更后，按页面提示更新或重新生成并应用。Monet 草稿通过「应用配色」提交，不改变当前开关。导入或预览成功不代表系统主题已经应用，实际支持取决于资源和系统。

## English

More control over per-app icons, a reorganized Monet editor, smoother search and refresh, and clearer management of large icon packs.

1. **Custom icons take final priority**

   Assign an icon from a local pack to an app and keep it across pack switches. Custom icons override other artwork; switching to or from kept originals requires confirmation. Saved entries open an original/custom comparison before editing or removal. Reapply after changes.

2. **Clearer scopes, previews and search**

   Counted views, scope filters and search help browse apps and icon resources. Opening a preview or selection step dismisses the keyboard while keeping the query. Existing results remain visible while new matches are computed, reducing loading flicker during typing. All/Unread release notes save reading per version, separately from restart advice.

3. **A focused Monet editor**

   Use quick dropdowns on the overview, separate sheets for color source, scheme and icon preview, and subpages for custom colors and palette details. Edits stay in a draft until submitted with the single Apply colors floating action. Applying preserves the current on/off state; use the switch separately. Refresh only reads system state. The help button explains drafts, the independent Monet switch, inspiration packs, and contrast.

4. **Better large-pack import and local application**

   Improved reading, validation and system Themes handoff for large ZIP/MTZ archives and complete Perfect iOS packs, with preparation progress, cancellation and working-space checks when needed. Eligible generated archives can be reused. Fixed false rejections of supported dynamic calendars and native palette templates while retaining checks against unknown programs.

5. **Smoother app updates and native pull refresh**

   Coalesced install, update and removal events to reread affected apps, reducing repeated catalog comparisons during scrolling. Native pull refresh on relevant pages handles disabled gestures and overscroll more consistently. Refined Glass toolbar spacing and tab shadows. MIUIX icons now use Glass throughout. Grouped action menus offer direct checked sorting options and filter submenus with the current selection.

6. **Manage icon-pack storage by category**

   See imported archive sizes and open separate MTZ/ZIP, Apple and Perfect storage controls. Preview memory, downloaded resources and generated archives have distinct cleanup actions. Keep latest generated cleans older generations after the next successful generation; manual imports remain separate.

7. **A 20-second review before exporting App logs**

   Export explains its purpose and unlocks confirmation after 20 seconds. App logs cover KeiHome UI, settings and crashes; icon, launcher and module feature issues still need LSPosed logs.

> After changing icon resources or rules, update or regenerate as prompted and apply the pack. Submit Monet drafts with Apply colors, which preserves the current on/off state. Importing or previewing a pack does not apply a system theme; support depends on resources and the system.

## 日本語

アプリ別アイコンのカスタマイズと Monet の配色編集を改善。検索・更新を滑らかにし、大容量アイコンパックのインポートとストレージ管理を分かりやすくしました。

1. **アプリ別カスタムアイコンを最優先に**

   ローカルパックのアイコンをアプリに指定し、パックを切り替えても使用できます。カスタムアイコンは最終的に優先され、元のアイコン保持との切り替えには確認が必要です。保存済み項目は比較画面から編集・削除します。変更後は再適用してください。

2. **対象の絞り込み・プレビュー・検索を改善**

   件数付きの表示切り替えと対象別の絞り込みでアプリやアイコンを探せます。プレビューや選択手順を開くとキーボードを閉じ、検索語は保持します。検索処理中も現在の結果を表示し、入力中の読み込み表示のちらつきを抑えます。更新履歴のすべて・未読はバージョン別に保存し、再起動案内とは別に管理します。

3. **Monet の配色編集を整理**

   概要のクイック選択、色の取得元・配色スタイル・プレビューの個別シート、色のカスタマイズとパレット詳細の子画面を用意しました。変更は下書きに保ち、共通の「配色を適用」フローティングボタンで反映します。適用しても現在のオン・オフは変わらず、切り替えは専用スイッチで行います。更新はシステム状態の読み取りのみです。 右上のヘルプに下書き、独立したスイッチ、インスピレーションパック、コントラストの説明をまとめました。

4. **大容量パックのインポートとローカル適用を改善**

   大容量 ZIP／MTZ と Perfect iOS 完全パックの読み取り・検証・システムテーマへの受け渡しを改善しました。準備の進捗とキャンセルに対応し、必要に応じて作業領域を確認します。条件を満たす生成済みアーカイブは再利用します。対応する動的カレンダーと標準配色テンプレートの誤拒否を修正し、不明なプログラムへの制限は維持します。

5. **アプリ更新と標準のプル更新を滑らかに**

   インストール・更新・削除の通知をまとめ、影響するアプリを再読み込みします。スクロール中の重複したカタログ比較を減らし、関連画面の標準プル更新と無効時の overscroll を整えました。Glass ツールバーの余白とタブの影も改善しました。 MIUIX アイコンを Glass に統一し、操作メニューを用途別に整理しました。並べ替えは選択状態を直接示し、フィルターのサブメニューには現在の選択を表示します。

6. **アイコンパックの保存容量を種類別に管理**

   インポート済みアーカイブの容量を表示し、MTZ／ZIP、Apple、Perfect を個別に管理できます。プレビューメモリ・取得済み画像・生成アーカイブの整理を区別しました。「最新の生成パックのみ保持」は次の生成成功後に古い生成物を整理し、手動インポートは別に保持します。

7. **App ログ出力前に 20 秒間確認**

   用途を説明し、20 秒後に出力確認を有効にします。App ログは KeiHome 自体の画面・設定・クラッシュ用です。アイコン、ランチャー、モジュール機能の問題には引き続き LSPosed ログを添えてください。

> アイコンの画像やルールを変更したら、画面の案内に沿って更新・再生成して適用してください。Monet の下書きは「配色を適用」で反映し、現在のオン・オフは保持します。インポートやプレビューだけではシステムテーマは適用されません。対応範囲はリソースとシステムによって異なります。
