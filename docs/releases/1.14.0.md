# KeiHome 1.14.0

本页与 App 内三语更新日志一致。对比基线为 1.13.0 公测版 `1.13.0+g89c8421.b0647.override`（`113000647`）。

## 简体中文

调整 Dock 玻璃留白，减少生成图标包的多余开销，并让图标包和 Monet 的预览、更新与应用更好找。

1. **Dock 左右边距与图标居中**

   开启 Dock 玻璃背景后，可调整两端图标到玻璃边缘的间距，0 dp 保持原来的左右边距。玻璃随可用宽度调整，图标和点击区域留在原位。开启或关闭桌面无字模式时，图标都能在玻璃底板内垂直居中。

2. **图标包减少多余的动态开销**

   生成或转换图标包时，日夜图案相同的普通图标会省去不必要的动态配置，减少桌面切换时的处理工作。真正的日夜变化、原版时钟和日历、实时 Monet 配色及系统兼容资源仍会保留。大包生成和导入也减少了重复解码、压缩和内存占用。

3. **导入异常可以重试**

   生成好的 ZIP 会在系统导入准备失败后保留，方便重新提交。系统主题处理大包较慢时，可继续查询原有导入的结果。

4. **全屏打开主题壁纸手动应用**

   可在图标包设置中开启「在主题壁纸中手动应用」，从 KeiHome 全屏打开已导入的图标包，再点「应用」。旧记录在主题壁纸中失效时会提示更新或重新导入，避免打开别的包。能否应用由主题壁纸决定，不兼容的包可能被拒绝或显示异常。

5. **图标包页面用底栏切换**

   完美图标补全计划可在生成、资源管理和图标预览之间直接切换。Apple 图标包把已匹配图标和自定义映射移到底栏，减少来回退回上页的操作。内置 ColorOS 样式缩略图和深浅色预览恢复显示。

6. **Monet 编辑、补全与安装分区**

   底栏可直达自定义色彩、配色详情和安装更新，两张色彩设置卡默认展开，并记住各自的收起状态。切换取色风格时，旧的应用结果及时清除，计算过程中也不再闪现缺少配色的提示。安装更新集中提供导入明暗、取色补全、满幅图标留白和 ColorOS 灵感安装。受支持的其他图标包也可对符合条件的图标取色和留白，部分缺少普通图标别名的原生分层资源也能参与取色。按提示更新或重新生成，并应用图标包后即可在桌面查看。

7. **微信冷启动图标补全**

   开启「启动图标补全」后，微信冷启动时，符合条件的纯色系统启动画面也能显示当前主题图标，缺少时使用应用原图。微信随后显示的自带开屏图案会保留。

8. **修复滚动时状态卡被裁切**

   上下滑动「沉浸式手势导航栏」设置时，状态卡的标题、状态标签和图示保持完整。更新后的 Glass 顶栏与标签栏也改善了渐进模糊和淡出衔接。

9. **日志反馈说明更清楚**

   导出 App 日志前会说明 App 日志和 LSPosed 日志各自适用的问题。如果不确定该反馈哪一份，请同时附上两份日志。

> 本版更新了桌面的原生库。覆盖安装后请手动重启设备，解锁进入桌面。要获得生成图标包的优化，请更新或重新生成图标包并应用。

## English

Adjust the Dock glass spacing, generate leaner icon packs, and find previews, updates, and application controls more easily.

1. **Dock side padding and icon centering**

   With Dock glass enabled, adjust the gap between the outer icons and the glass edges. 0 dp keeps the default side spacing. The glass fits the available width while icons and touch targets stay in place. Icons are vertically centered in the glass with launcher labels shown or hidden.

2. **Less dynamic work for generated icon packs**

   Generation and conversion omit redundant dynamic selectors for ordinary icons with identical light and dark artwork, reducing work during launcher transitions. Distinct light and dark artwork, authored clocks and calendars, live Monet colors, and resources needed for system compatibility are preserved. Large packs also require less repeated decoding, compression, and memory during preparation.

3. **Recover from import problems**

   The generated ZIP is kept if preparation for system import fails, so you can try again. If Themes takes longer to process a large pack, you can check the result of the original import.

4. **Apply manually in full-screen Themes**

   Enable Manual application in Themes in icon pack settings to open an imported pack in full screen and tap Apply. If Themes no longer has the local record, KeiHome asks you to update or reimport the pack and avoids opening a different one. Themes decides whether the pack can be applied. Incompatible packs may be rejected or display incorrect icons.

5. **Bottom tabs for icon packs**

   Switch between generation, resource management, and icon preview in Perfect Icons. Matched icons and custom mappings are now tabs in the Apple icon pack. Built-in ColorOS style thumbnails and light and dark previews are visible again.

6. **Separate tabs for Monet colors and installation**

   Open Custom colors, Palette details, and Install and update from the bottom bar. The two color cards start expanded and remember their own state. Switching color styles clears the previous apply confirmation and keeps the missing-color help out of view while the new palette is calculated. Install and update groups icon appearance, fallback coloring, full-bleed padding, and ColorOS Inspiration installation. Compatible icons from other packs can also use coloring and padding, including coloring for some native layer pairs without flat aliases. Update or regenerate as prompted, then apply the icon pack to see the changes on the launcher.

7. **WeChat cold-start icon completion**

   With Fill missing launch icons enabled, eligible plain system splash screens can display the current theme icon on a WeChat cold start. The original app icon is used when the theme has no match. WeChat still displays its own splash artwork after the system screen.

8. **Gesture settings card stays visible while scrolling**

   The status title, badges, and illustration remain visible when scrolling Immersive gesture bar settings. Updated Glass top bars and tabs also improve how progressive blur and fades transition.

9. **Clearer log export guidance**

   Before exporting App logs, KeiHome explains which issues require App logs and which require LSPosed logs. Attach both if you are unsure.

> This release updates the native launcher library. After installing, manually restart your device and unlock to the home screen. To get the icon pack generation improvements, update or regenerate the pack and apply it.

## 日本語

Dock のガラス背景の余白を調整できるようにし、アイコンパック生成の負荷を軽減しました。プレビューや更新、適用にもアクセスしやすくなりました。

1. **Dock の左右の余白とアイコンの中央揃え**

   Dock のガラス背景を有効にすると、両端のアイコンとガラスの縁の間隔を調整できます。0 dp は既定の間隔です。ガラスは利用できる幅に収まり、アイコンとタップ領域の位置は変わりません。ホーム画面のラベルを表示する場合も、非表示にする場合も、アイコンはガラスの上下中央に揃います。

2. **生成するアイコンパックの動的処理を削減**

   生成や変換の際、ライトとダークで同じ画像を使う通常のアイコンでは、不要な切り替え設定を省きます。これにより、ホーム画面の切り替え時の処理が減ります。明暗で異なる画像、元の時計やカレンダー、Monet のリアルタイム配色、システム互換に必要なリソースは維持します。大きなパックの準備では、画像の再デコードや再圧縮、メモリ使用量も削減しました。

3. **インポートに失敗した場合の再試行**

   システムへのインポート準備が失敗しても、生成済み ZIP を残すので再試行できます。テーマで大きなパックの処理に時間がかかるときは、同じインポートの結果を確認できます。

4. **全画面のテーマで手動適用**

   アイコンパック設定でテーマでの手動適用を有効にすると、インポート済みのパックを全画面で開き、「適用」を押せます。テーマから古い記録が消えている場合は、別のパックを開かずに更新または再インポートを案内します。適用できるかどうかはテーマが判断し、互換性のないパックは拒否されたり、アイコンの表示に問題が出たりする場合があります。

5. **アイコンパックを下部タブで切り替え**

   Perfect Icons の生成、リソース管理、アイコンのプレビューを下部から切り替えられます。Apple アイコンパックの一致したアイコンとカスタムマッピングもタブに移動しました。内蔵 ColorOS スタイルのサムネイルとライト・ダークのプレビューが再び表示されます。

6. **Monet の配色編集と導入をタブに整理**

   下部から色のカスタマイズ、パレットの詳細、導入と更新に移動できます。色の設定カードは初めから展開され、個別に状態を記憶します。配色スタイルの切り替えで前回の適用結果が消え、新しい配色の計算中に色がないという案内が一瞬表示される問題も修正しました。「導入と更新」にはインポート時の明暗、未対応アイコンの配色補完と余白、ColorOS インスピレーションの導入をまとめました。他の対応パックでも対象アイコンに配色補完や余白を使え、通常の画像エイリアスを持たない一部のネイティブレイヤーも配色できます。案内に沿ってパックを更新または再生成し、ホーム画面に適用してください。

7. **WeChat のコールドスタート時にアイコンを補完**

   起動アイコンの補完を有効にすると、WeChat のコールドスタートで、条件を満たす単色のシステム起動画面に現在のテーマアイコンを表示できます。一致するアイコンがない場合はアプリ本来のアイコンを使います。その後の WeChat 独自の起動画面は従来どおり表示されます。

8. **スクロール中のジェスチャー設定カードの欠けを修正**

   没入型ジェスチャーバーの設定をスクロールしても、状態カードの見出し、バッジ、イラストが欠けなくなりました。Glass の上部バーとタブも更新し、段階的なぼかしとフェードの切り替えを改善しました。

9. **ログ共有の案内を改善**

   アプリログの書き出し前に、アプリログと LSPosed ログが必要なケースを確認できます。どちらか分からない場合は、両方を添付してください。

> このバージョンではホーム画面のネイティブライブラリを更新しています。上書きインストール後、端末を手動で再起動し、ロックを解除してホーム画面を開いてください。アイコンパック生成の改善を反映するには、パックを更新または再生成し、適用してください。
