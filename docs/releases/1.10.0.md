# KeiHome 1.10.0

版本前缀：`1.10.0`；本地发布 tag：`v1.10.0`。版本日期：2026-11-15（Asia/Singapore）。创建本地 tag 不代表已推送或公开发布。

比较基线：实际公开的 `1.9.0+g70ea216.b0394`（versionCode `109000394`，源码 `70ea21606be2d8277da0c1031853d94b257b396f`）。正文覆盖该公开包之后的用户可见变化；旧 `v1.9.0` tag 指向更早的准备提交，继续保留原样。

以下三语正文与 App 内 `release_notes_1_10_0_introduction`、`release_notes_1_10_0_changes`、`release_notes_1_10_0_footnote` 对应，保留既有 1.9.0 条目。

## 简体中文

完善 OS4 交互与状态提示，加快图标信息读取，修正完美图标的深色显示与通知图标，并改进 Apple 匹配和热重载稳定性。

1. **更顺手的 OS4 搜索与浮层**

   退出搜索编辑后保留关键词、筛选和返回位置；短说明使用贴近按钮的玻璃浮层，完善关闭动画与操作衔接。切换视图使用分段页签，较长分类可横向滚动。更新 Glass 图标，改善折叠标题对齐与顶部渐隐。

2. **状态详情集中到面板**

   运行状态与 Monet 详情改为独立底部面板，减少页面滚动。首次读取连接、授权和功能状态时显示中性的加载提示，避免尚未读完就闪红；已确认的失败仍正常提示。

3. **明确首次激活步骤**

   首次启用并授权后，提示重启系统并解锁进入桌面；跳过向导也能在状态页看到提醒。已激活用户的普通更新仍通常使用 API 102 自动热重载。

4. **浮动导入与精简帮助**

   APK、MTZ／ZIP 页面新增浮动导入按钮，通过底部面板说明导入方式。图标包长说明收进帮助面板，各相关页面首次进入时展示一次，之后可从帮助按钮重看；进度、错误和重要提示仍留在页面。

5. **加快图标信息读取与跳转**

   减少大量应用和大图标包的重复读取、校验与主线程处理，分批显示已就绪内容，并保留筛选结果。状态卡默认可直达当前图标包，无法确认来源时返回总览，也可在设置中关闭直达。

6. **默认仅保留最新生成包**

   Apple 与完美图标包各自保留最新生成版本，新包成功保存后清理旧生成版本；可在更多设置中关闭，手动导入的图标包不受影响。

7. **完善完美图标动态分层**

   保留符合规则的原生动态图层与透明度，改善日历文字和深浅色联动；修正天气深色云朵的形状与大小，以及游戏中心手柄的半透明轮廓和背景残留。

8. **改善深色文字与封面**

   提高部分品牌小字在深色背景上的可读性，保留品牌色和原有图案；修正生成图标包静态封面中文字的灰边与底色残留，让封面更贴近动态图标效果。

9. **修正通知缩略图与超级岛图标**

   改善折叠通知缩略图的方形边角，以及首次自动热重载通知的图标遮罩；适配超级岛默认应用图标入口，保留通知自带图片、媒体封面和自定义内容。

10. **Apple 匹配缓存与重试更清楚**

   修复成功搜索记录被误当作七天冷却的问题，已保存的候选和未匹配记录可手动重试；近期结果复用缓存，真实请求失败和服务器限流仍按提示等待。

11. **粉白图标与深浅启动画面**

   恢复 Kei 樱花粉白图标配色，启动画面采用对应的浅樱粉／深玫瑰底色，并跟随 App 保存的外观设置衔接主界面。

12. **9248 适配与初始化稳定性**

   补充 9248 版桌面的 Monet、Dock 和图像恢复结构适配；隔离 SystemUI 各项初始化，合并重复恢复任务，完善 API 102 热重载时的监听、缓存与后台任务交接。

13. **导出 App 日志前再次确认**

   导出前显示说明并等待 5 秒后确认。App 日志用于本 App 的界面、设置等异常；桌面、图标或 Hook 功能异常仍需提供 LSPosed 日志。

> 图标修正需更新或重新生成图标包后应用。效果取决于资源与系统支持；第三方 ROM 兼容性仍需验证，部分文件夹预览异常尚未解决，Apple 服务器限流仍然有效。

## English

Improved OS4 interactions and status guidance, made icon information faster to load, corrected Perfect Icons dark artwork and notification icons, and improved Apple matching and hot-reload stability.

1. **Smoother OS4 search and overlays**

   Leaving search editing keeps the query, filters and return position. Short explanations use glass popups beside their buttons, with improved dismissal and action handoff. View switches use segmented tabs, while long category lists can scroll horizontally. Updated Glass icons, collapsed title alignment and the top-bar fade.

2. **Status details in dedicated sheets**

   Runtime and Monet details now open in separate bottom sheets to reduce page scrolling. Initial connection, authorization and feature checks show neutral loading states instead of briefly flashing red; confirmed failures still show their warnings.

3. **Clearer first-activation steps**

   After first enabling and authorizing the module, guidance asks you to restart the device and unlock to the home screen. The reminder stays on Status even if you skip the guide. Ordinary updates after activation still normally use API 102 automatic hot reload.

4. **Floating import actions and compact help**

   APK and MTZ/ZIP pages have floating import buttons with a guidance sheet. Long icon-pack instructions move into help sheets, shown once on first entry to each relevant page and available again from Help. Progress, errors and important notices stay on the page.

5. **Faster icon information and direct navigation**

   Reduced repeated reads, validation and main-thread work for large app inventories and icon packs. Ready content appears progressively, and filter results are retained while loading. Status opens the current pack directly by default, falling back to the overview if its source cannot be confirmed; this shortcut can be disabled.

6. **Keep only the latest generated pack by default**

   Apple and Perfect Icons each retain their latest generated version, removing older generated versions after the new pack is saved successfully. Turn this off in More settings to keep generation history. Manually imported packs are unaffected.

7. **Improved Perfect Icons dynamic layers**

   Preserved supported native dynamic layers and transparency, and improved Calendar text and light/dark updates. Corrected dark Weather cloud shape and size, plus the translucent Game Center controller outline and background residue.

8. **Clearer dark lettering and cover images**

   Improved small brand lettering on dark backgrounds while preserving brand colors and artwork. Corrected gray text edges and background residue in generated pack cover images to better match their dynamic icons.

9. **Notification thumbnails and Super Island icons**

   Improved square corners in folded notification thumbnails and icon masking in the first automatic hot-reload notice. Added support for the default application-icon path in Super Island, preserving supplied notification pictures, media artwork and custom content.

10. **Clearer Apple matching cache and retries**

   Fixed successful search history appearing as a seven-day cooldown. Saved reviews and misses can be retried manually, with recent results reused from cache. Failed requests and server rate limits still require the indicated wait.

11. **Pink-and-white icon and themed splash screens**

   Restored the Kei sakura pink-and-white icon palette. Startup uses pale sakura or dark rose backgrounds and follows the saved app appearance through the transition to the main screen.

12. **Launcher 9248 and initialization stability**

   Added support for Launcher 9248 Monet, Dock and image-recovery structures. Isolated SystemUI initialization stages, coalesced duplicate recovery work, and improved listener, cache and background-task handoff during API 102 hot reload.

13. **Confirm before exporting App logs**

   Log export now explains its purpose and requires confirmation after a five-second wait. App logs cover this app’s interface and settings issues; launcher, icon and hook issues still require LSPosed logs.

> Update or regenerate and apply your icon pack to receive artwork fixes. Results depend on resources and system support. Third-party ROM compatibility still needs validation, some folder preview issues remain unresolved, and Apple server rate limits remain in effect.

## 日本語

OS4 の操作と状態案内を改善し、アイコン情報の読み込みを効率化しました。Perfect Icons のダーク表示と通知アイコンを修正し、Apple の照合とホットリロードの安定性も改善しました。

1. **OS4 の検索とポップアップを改善**

   検索の編集を終了しても、キーワード、絞り込み、戻り先の位置を保持します。短い説明はボタン付近のガラスポップアップにまとめ、閉じるアニメーションと次の操作への移行を改善しました。表示切り替えにはセグメントタブを使い、長いカテゴリ一覧は横にスクロールできます。Glass アイコン、折りたたみ時のタイトル配置、上部バーのフェードも改善しました。

2. **状態の詳細を専用シートに整理**

   実行状態と Monet の詳細をそれぞれ下部シートに移し、ページのスクロールを減らしました。接続、認可、機能の初回確認中は中立的な読み込み表示にし、一瞬赤くなる問題を改善しました。確認済みの失敗は引き続き警告します。

3. **初回有効化の手順を明確化**

   初回の有効化と認可後は、端末を再起動してロックを解除し、ホーム画面へ進むよう案内します。ガイドをスキップしても状態ページに案内が残ります。有効化済みユーザーの通常更新では、引き続き原則として API 102 の自動ホットリロードを利用します。

4. **読み込み用フローティングボタンと簡潔なヘルプ**

   APK、MTZ／ZIP ページにフローティングボタンを追加し、下部シートで読み込み方法を案内します。長い説明はヘルプシートにまとめ、各対象ページへの初回アクセス時に一度表示し、後からヘルプボタンで再表示できます。進捗、エラー、重要な案内はページに残します。

5. **アイコン情報の読み込みと移動を効率化**

   アプリやパックが多い場合の重複読み取り、検証、メインスレッドの処理を減らしました。準備できた内容から表示し、読み込み中も絞り込み結果を保持します。状態カードから適用中のパックへ直接移動する設定は既定で有効です。出所を確認できない場合は一覧を開き、直接移動は設定で無効にできます。

6. **生成パックは既定で最新版のみ保持**

   Apple と Perfect Icons それぞれで最新の生成版を保持し、新しいパックの保存に成功してから古い生成版を削除します。生成履歴を残す場合は詳細設定で無効にできます。手動で読み込んだパックは対象外です。

7. **Perfect Icons の動的レイヤーを改善**

   対応するネイティブ動的レイヤーと透明度を保持し、カレンダーの文字とライト／ダークの更新を改善しました。ダーク表示の天気の雲の形と大きさ、ゲームセンターの半透明なコントローラー輪郭と背景の残りを修正しました。

8. **ダーク表示の文字とカバー画像を改善**

   ブランド色と元の絵柄を保持しながら、暗い背景で一部の小さなブランド文字を読みやすくしました。生成パックの静止カバー画像に残る文字の灰色の縁や背景色も修正し、動的アイコンの表示に近づけました。

9. **通知サムネイルとスーパーアイランドのアイコンを修正**

   折りたたまれた通知のサムネイルの四角い角と、初回の自動ホットリロード通知のアイコンマスクを改善しました。スーパーアイランドの標準アプリアイコン経路に対応し、通知独自の画像、メディアのアートワーク、カスタム内容を保持します。

10. **Apple 照合のキャッシュと再試行を明確化**

   検索成功の履歴を 7 日間の待機と誤表示する問題を修正しました。保存済みの候補や未一致の記録は手動で再試行でき、直近の結果はキャッシュを再利用します。リクエスト失敗やサーバーのレート制限には引き続き表示どおりの待機が必要です。

11. **ピンクと白のアイコンと起動画面**

   Kei の桜色と白のアイコン配色を復元しました。起動画面は淡い桜色／暗いローズ色の背景を使い、保存済みのアプリ外観設定に合わせてメイン画面へ移行します。

12. **ランチャー 9248 と初期化の安定性を改善**

   ランチャー 9248 の Monet、Dock、画像復旧の構造に対応しました。SystemUI の初期化を機能別に分離し、重複する復旧処理をまとめ、API 102 ホットリロード時のリスナー、キャッシュ、バックグラウンド処理の引き継ぎを改善しました。

13. **アプリログの書き出し前に再確認**

   目的を説明し、5 秒待ってから書き出しを確認するようにしました。アプリログは本アプリの画面や設定などの問題を対象とします。ランチャー、アイコン、Hook 機能の問題には引き続き LSPosed ログが必要です。

> 画像の修正を反映するには、アイコンパックを更新または再生成して適用してください。効果はリソースとシステムの対応状況によって異なります。サードパーティ製 ROM の互換性は引き続き検証が必要で、一部のフォルダープレビューの問題は未解決です。Apple サーバーのレート制限も引き続き適用されます。
