# KeiHome v1.5.0

2026-11-07

相较上一公测版 `1.4.0+g112166c.b0202`：

- 修复 9226 版桌面在部分 DPI／图标尺寸组合下，Dock 放满 5 个 App 后柔光玻璃消失的问题。
- 补全 8604 版桌面的 Monet、Dock 等动态适配，修复自动热重载期间的监听回收竞态。
- 新增 Dock 的 Pad 风格、屏幕同心参考及自定义圆角，支持高度和上下位置调节。
- 优化点击图标、返回桌面和跨页／多选拖放时的资源回收，修正编辑模式的动画联动。
- 优化生成图标的图片复用、打包与 Monet 配置同步，减少冗余资源和配置读取开销。
- 新增“仅为已安装应用生成图标”选项，默认关闭，可按需缩减生成范围。
- 完善大图标包、慢速主题操作的等待与自动复查，减少失败误报；修复部分图标包来源识别与补全状态刷新异常。
- 将“图标包与操作”独立为设置子页，统一悬浮操作按钮，完善使用向导和大字体显示。
- 改进日志文件命名，补充机型、系统和桌面版本等环境信息，明确区分 LSPosed 功能日志与 App 自身日志。
