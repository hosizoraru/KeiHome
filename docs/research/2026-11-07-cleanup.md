# November 7, 2026 storage cleanup

Source baseline: `3f5be4c`, following the signed v1.5.0 release. Cleanup changes
local storage and this receipt only. No application code, release tags, installed
applications, device data, Downloads, or global dependency caches were changed.

## Removed regenerable files

- App generated sources, intermediates, Kotlin output, temporary output and
  duplicate build-output APKs.
- Native CMake configuration caches and build-logic build/cache directories.
- Project-local Gradle caches, preserving `.gradle/keihome-version/` verbatim.
- Three obsolete module/test APKs, confirmed by their package metadata, and 207
  AndroidX dependency JARs used by the retired clock experiment. Experiment
  sources, custom diagnostic JARs, and research records remain.

Current `app/build/outputs/mapping/`, lint reports and test results remain.
The build-output Release APK and unstripped native library were verified against
their v1.5.0 archive before removing their regenerable copies.

  483,965,880-byte gzip-compressed tar archive.
- 26 older Release R8 mappings: 1,580,577,679 bytes became 103,320,774 bytes in
  adjacent `mapping.txt.gz` files.
- Every decoded archive member and mapping was checked against its original
  SHA-256 before its original file was removed.
- Native `gzip` and `tar` recovery commands were also tested on one mapping and
  one trace, with matching SHA-256 results and automatic temporary-file cleanup.
- Raw mappings remain for the reported public beta `104000202`, the preceding
  final `104000244`, and the current release `105000218`.
