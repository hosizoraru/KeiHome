# KeiHome 1.9.0

发布日期：2026-11-13（按 `v1.9.0` 目标提交时间）

范围：`v1.8.0..v1.9.0`。

修复图标跨界面显示与动态深浅色联动，完善补全控制、预览与 OS4 Glass 交互，并优化高频 Hook 和资源管理。

1. **修复部分应用图标变方和边缘异常**

   统一桌面入口别名、自适应图标与最终遮罩的处理，改善部分应用在桌面、最近任务、分享、设置等位置显示不一致的问题，并保留应用自身可切换的图标。

2. **完善动态分层图标深浅色刷新**

   修复日历等动态图标在桌面已切换深色、通知中仍停留浅色的情况，完善异步图标就绪后的界面刷新，并继续保留动态资源和正确日期。

3. **预览更贴近实际应用效果**

   统一应用列表、图标包和详情预览的圆角、透明边缘与遮罩规则；已应用主题读取实际发布的图标，遮罩对比与待生成设置独立。将导入、应用等操作移到预览右侧，减少空白和重复占位。

4. **保留原始图标与推荐映射**

   可按应用选择保留自身图标，列表支持搜索、筛选和排序。新增推荐映射子页，独立控制按应用名称匹配系统图标、Telegram 官方 Play／Web／Beta 渠道图标共享和内置 ColorOS 主题商店映射；保留已有适配与原图标名单的优先级。

5. **独立的完美图标补全**

   完美补全改为独立选项，可为 ColorOS 和其他图标包补齐未覆盖的系统及第三方应用。启用前检查已下载资源，推荐 HyperOS4；启用期间暂停系统图标回退，关闭后恢复原选择。

6. **完美图标连接设置与状态恢复**

   可为完美图标客户端选用 HTTPS 加速地址，以及跟随系统、直连、HTTP 或 SOCKS 连接方式，不修改设备全局代理。直接进入子页也会加载完整目录；回到应用时统一刷新本地下载与移除状态，并在失败后有限重试。失败与冷却提示统一放入 OS4 卡片，已下载资源仍可离线使用。

7. **统一 OS4 Glass 交互**

   完善原生选择项、Glass 按压、标签栏、底部面板与浮动工具栏；Apple 映射支持多选管理和图标检查。修复 Monet 等展开卡片内容堆叠，统一列表筛选、排序及操作布局。

8. **导入图标包可单独移除**

   为本地导入的 MTZ／ZIP 等资源提供二次确认后的移除操作，保留源文件和已应用主题。列表使用紧凑数量标识，导入、删除及资源变化后同步刷新相关页面与空间统计。

9. **缓存管理与状态信息完善**

   默认清理提醒固定为 520 MB，不再随完美图标下载变化；增加应用日志统计与跳转，并为缓存分类提供说明。状态页显示 App 版本前缀，使用向导同步补充补全、保留原图标和推荐映射入口。向导采用独立全屏布局，内容可在顶栏后平滑滚动并渐隐，悬浮操作保持可用。

10. **优化运行开销与发布兼容**

   优化图标缓存、反射访问与日志处理，减少高频路径的重复工作；保留及时刷新、API 102 自动热重载及旧代回收，并同步更新依赖、完善 R8 优化与运行入口保护。

> 图标效果取决于应用、图标包和系统提供的资源。修改补全、推荐映射、遮罩、保留原图标名单或生成范围后，请更新或重新生成图标并应用；仅预览不会修改系统主题。
