All 26 November 3 launcher-label Perfetto traces and the large activation log
were losslessly compressed, rather than discarded. Summaries, screenshots and
acceptance reports remain at their existing paths. Original evidence paths map
directly to archive member names in:

```text
.artifacts/research/cleanup-20261104/launcher-labels-raw-evidence.tar.gz
SHA-256: 7ab2c4097e4e6f5b7e59807ce338914056772e3048d5a225e9f5cbf7175ccabf
```

Read or recover an individual member without expanding the whole archive:

```sh
tar -xOf .artifacts/releases/101000181/diagnostics.tar.gz \
  app/build/outputs/mapping/release/mapping.txt > /tmp/keihome-101000181-mapping.txt

tar -xOf .artifacts/research/cleanup-20261104/launcher-labels-raw-evidence.tar.gz \
  .artifacts/research/launcher-labels/performance/accepted-marquee-dense.pftrace \
  > /tmp/keihome-accepted-marquee-dense.pftrace
```

## Verification and scope

The local `plan.json` and `receipt.json` under
`.artifacts/research/cleanup-20261104/` record the explicit removal paths,
protected-file hashes, removed APK hashes, archive members and size accounting.
Every archive member was read back and hash-verified before removing its source.
All **13,463** protected files passed post-cleanup SHA-256 checks. Each deletion
target was ignored, contained no tracked file, and excluded protected inputs.
No active build or capture was using the removed files.

The Themes versions were checked directly with `aapt2 dump badging`. Git
whitespace and working-tree checks accompany this documentation change. No new
Gradle build or device test is needed for storage cleanup; it would recreate the
removed caches. No AVD, physical phone, global dependency cache, signing key,
other project or Downloads backup was changed by this cleanup.

Local proprietary APKs and binary evidence remain ignored and are not part of
the GitHub push. The push preserves the existing implementation commit history
and adds this cleanup receipt.
