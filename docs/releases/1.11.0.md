版本前缀：`1.11.0`；目标发布 tag：`v1.11.0`。本文为发布准备文案，不代表已创建 tag、构建最终安装包或公开发布。目录日期以最终 tag 目标提交的 committer timestamp 为准。

公开升级路径为 **1.9.0 → 1.11.0**：1.10.0 尚未公开发布，升级界面会同时展开 [1.10.0](1.10.0.md) 与本版本的日志。本文的原生适配增量以本地准备 tag `v1.10.0` 为比较基线；保留已有日志原文，避免在两个同时展开的版本中重复列举同一项功能。

## 简体中文

适配 9258 版桌面，改进原生结构与依赖图的动态解析，并明确首次启用、原生代码升级和版本重启建议的区别。

1. **按结构解析桌面依赖图**

   根据实际代码结构与依赖关系定位功能，修正代码和数据重定位导致的误拒，不使用版本号或固定地址硬编码适配。包含 9258 在内的 10 个版本样本检查通过；这仍不保证任意未知版本都兼容。

2. **9258 的 Selection、Monet、Dock 与图像恢复适配**

   完善 Selection 依赖图、Monet 图标处理、Dock 玻璃和 ImageRecovery 图像恢复的结构识别，保留必要的校验；结构不匹配或无法唯一确认时，不启用对应能力。

3. **原生代码升级需要重启系统**

   本版包含新的 .so 原生代码，升级后请手动重启系统，再解锁进入桌面。API 102 自动热重载仅更新 Java 部分，不能替换进程中已加载的原生库。

4. **每个版本一次的重启建议**

   升级后看完更新日志、返回主页时显示一次重启建议，确认按钮需等待 5 秒后可用。确认仅表示已阅读，系统重启由你手动完成。

5. **开源声明与项目协议**

   开源组件按用途拆分子页并保留全局搜索，优化许可证阅读页的 OS4 交互与 Glass 操作，在关于中新增项目协议入口，提供 Apache 2.0 项目许可。第三方组件保留各自许可和署名，并补充 MiuiBackGestureHook 的研究参考致谢。

> 首次启用仍必须在启用模块、授权作用域后重启系统；跳过向导或确认建议不能替代重启。兼容性取决于实际桌面结构与系统支持，10 个版本样本通过不代表任意未知版本均可用。

## English

Added support for Launcher 9258, improved dynamic resolution of native structures and dependency graphs, and clarified first activation, native code updates and version restart advice.

1. **Resolve launcher dependency graphs by structure**

   Locate features from actual code structures and dependencies, correcting false rejections caused by code and data relocation without hardcoded version checks or fixed addresses. Checks passed for 10 version fixtures, including 9258; this still does not guarantee compatibility with every unknown version.

2. **Launcher 9258 Selection, Monet, Dock and image recovery**

   Improved structure recognition for Selection dependency graphs, Monet icon processing, Dock glass and ImageRecovery while retaining required checks. A capability stays disabled if its structure does not match or cannot be uniquely identified.

3. **Native code updates require a system restart**

   This release includes new .so native code. After upgrading, manually restart the device, then unlock to the home screen. API 102 automatic hot reload updates only the Java part; it cannot replace native libraries already loaded in a process.

4. **Restart advice once per version**

   After reading the upgrade notes and returning to the main page, restart advice appears once for that version. Its confirmation button becomes available after five seconds. Confirmation only acknowledges the advice; you restart the device manually.

5. **Open-source notices and project license**

   Grouped open-source components into purpose-based subpages with global search, refreshed license readers with OS4 interactions and Glass actions, added a project-license entry in About, and added the Apache 2.0 project license. Third-party components retain their own licenses and attribution, including acknowledgements for MiuiBackGestureHook research.

> First activation still requires a system restart after enabling the module and granting scopes. Skipping the guide or acknowledging advice does not replace that restart. Compatibility depends on actual launcher structures and system support; passing 10 version fixtures does not guarantee every unknown version will work.

## 日本語

ランチャー 9258 に対応し、ネイティブ構造と依存関係グラフの動的解析を改善しました。初回有効化、ネイティブコードの更新、バージョンごとの再起動案内の違いも明確にしました。

1. **構造に基づくランチャー依存関係グラフの解析**

   実際のコード構造と依存関係から機能を特定し、コードやデータの再配置による誤った拒否を修正しました。バージョン番号や固定アドレスのハードコードには依存しません。9258 を含む 10 バージョンのサンプルで検証に合格しましたが、任意の未知のバージョンへの対応を保証するものではありません。

2. **9258 の Selection、Monet、Dock、画像復旧に対応**

   必要な検証を維持しながら、Selection の依存関係グラフ、Monet のアイコン処理、Dock のガラス表示、ImageRecovery の画像復旧の構造認識を改善しました。構造が一致しない場合や一意に特定できない場合は、該当機能を有効にしません。

3. **ネイティブコードの更新には端末の再起動が必要**

   本バージョンには新しい .so ネイティブコードが含まれます。更新後は手動で端末を再起動し、ロックを解除してホーム画面を開いてください。API 102 の自動ホットリロードで更新できるのは Java 部分のみで、プロセスに読み込み済みのネイティブライブラリは置き換えられません。

4. **バージョンごとに一度の再起動案内**

   更新履歴を読んでアプリのメイン画面に戻ると、そのバージョンの再起動案内を一度表示します。確認ボタンは 5 秒後に有効になります。確認は案内を読んだことの記録であり、端末の再起動は手動で行います。

5. **オープンソース表記とプロジェクトライセンス**

   コンポーネントを用途別の子画面に分けて全体検索を残し、ライセンス閲覧を OS4 と Glass 操作に合わせて改善しました。「このアプリについて」にプロジェクトライセンスを追加しました。Apache 2.0 のプロジェクトライセンスを掲載し、第三者のライセンスと帰属表示を保持します。MiuiBackGestureHook の研究への謝辞も追加しました。

> 初回の有効化では、モジュールを有効にしてスコープを許可した後、引き続き端末全体の再起動が必須です。ガイドのスキップや案内の確認では代わりになりません。互換性は実際のランチャー構造とシステムの対応状況に依存し、10 バージョンのサンプルでの合格は任意の未知のバージョンでの動作を保証しません。

- **9258 动态解析**：`5bf8c00` 修复 Selection、Dock、ImageRecovery 的结构识别和重定位误拒；[9258 兼容性记录](../launcher-9258-compatibility.md#最终验证)及[原生样本矩阵](../launcher-native-matrix.md)记录 Selection、Tint、ImageRecovery、Monochrome gate 与 Dock 的十样本验证。生产契约仍由旧九样本生成，9258 作为留出样本，不增加按版本号、库哈希或固定地址分支的适配。样本和 ARM64 模型检查通过不等于任意未知版本、第三方 ROM 或所有 Dart GC／GPU 场景均通过。
